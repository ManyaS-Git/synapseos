# SynapseOS Demonstration & Walkthrough Guide

**Version**: 0.2.0  
**Target Scenario**: Complete Memory-to-Action Loop & Evidence-Backed RAG  

This guide provides a step-by-step walkthrough to demonstrate SynapseOS live in under 5 minutes.

---

## 1. Environment Setup & Launch

### Step 1: Start Backend Server
```bash
cd apps/api
..\..\.venv\Scripts\activate  # Windows
# or: source ../../.venv/bin/activate (Linux/macOS)
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Step 2: Start Web Frontend
```bash
cd apps/web
npm run dev
```

Open your browser to: **`http://localhost:3000`**

---

## 2. Step-by-Step Demonstration Scenario

### Step 1: Log in & View Dashboard
1. Open `http://localhost:3000/login`.
2. Log in using your credentials (or register a new user on `/register`).
3. Notice the green **"Nebius x NVIDIA Nemotron Active"** badge on the dashboard.
4. Click **"Launch Assistant"** or navigate to **Assistant Copilot** in the sidebar.

---

### Step 2: Ingest Context (Manual or Document Upload)
1. In the sidebar, click **Memories -> Create** (`/memory/create`).
2. You will see two tabs: **Manual Input** and **Document Ingestion (PDF, MD, TXT)**.
3. Switch to **Document Ingestion**.
4. Select a markdown or text file (or type in manual input):
   - **Title**: `Nebius Token Factory GPU Architecture`
   - **Content**: `SynapseOS runs its heavy agent reasoning workloads on Nebius Token Factory clusters running NVIDIA H100 and L40S Tensor Core GPUs in Europe-West.`
   - **Type**: `knowledge`
   - **Tags**: `nebius, nvidia, gpu`
5. Click **Create Memory** (or **Ingest Document**).
6. The system computes a 768-dimensional normalized embedding, generates a graph node, and redirects to the memory detail page.

---

### Step 3: Inspect Memory & Knowledge Graph
1. Navigate to **Memories -> All Memories** (`/memory`). Verify your new memory appears in the list.
2. Navigate to **Knowledge Graph** (`/memory/graph`).
3. Explore the visual node representation of your knowledge interconnected across your workspace.

---

### Step 4: Ask an Evidence-Backed Question (RAG with Citations)
1. Navigate to **Assistant Copilot** (`/assistant`).
2. Type in the message composer:
   > *"What GPU infrastructure does SynapseOS use on Nebius Token Factory?"*
3. Send the message.
4. Observe the response generated by NVIDIA Nemotron:
   - Notice the citation badge: `[1] Nebius Token Factory GPU Architecture`.
   - Click the citation badge or **Show Sources** drawer to view the verbatim excerpt and similarity score (e.g. `0.89`).

---

### Step 5: Test the Strict Abstention Guard
1. In the Assistant Copilot, ask an unsupported or out-of-domain question:
   > *"What was the closing stock price of Apple Inc on January 15, 2021?"*
2. Send the message.
3. Observe the response:
   - SynapseOS displays an explicit warning indicator: **`[Abstained]`**.
   - The assistant states that no matching evidence exists in workspace memories and refuses to hallucinate facts.

---

### Step 6: Trigger the Bounded Agent Runtime (Planning & Consequential Action)
1. In the Assistant Copilot, instruct the agent:
   > *"Create project Mobile Client Launch for SynapseOS and research best practices."*
2. Send the message.
3. Observe the execution behavior:
   - NVIDIA Nemotron deconstructs the request into an `AgentPlan` with 2 steps.
   - **Step 1 (Safe)**: `web_research` runs automatically and marks status as `completed`.
   - **Step 2 (Consequential)**: `create_project` pauses execution and marks status as `awaiting_approval`.
   - An interactive amber banner appears: **`Action Approval Required: Create project Mobile Client Launch`**.

---

### Step 7: Human-in-the-Loop Approval & Verification
1. Click **Approve & Execute**.
2. The runtime validates the approval session token and executes the project creation.
3. The step transitions to green: **`Completed`**.
4. Navigate to **Projects** (`/projects`) in the sidebar to verify that `Mobile Client Launch` has been genuinely created in the database!

---

### Step 8: Controlled Reflection & Memory Continuity
1. Return to **Assistant Copilot** (`/assistant`).
2. Notice the **Reflection Card** beneath the completed execution steps:
   - Displays **Task Summary** and **Lessons Learned**.
3. In a new session, ask:
   > *"What projects have we recently planned or created?"*
4. The system retrieves the newly created project and reflection records from persistent memory!

## 3. Troubleshooting & Recovery

| Issue | Cause | Solution |
|:------|:------|:---------|
| **CORS error in browser** | API running on different port | Ensure `NEXT_PUBLIC_API_URL=http://localhost:8000` in `.env.local` or web config. |
| **Qdrant / Neo4j connection warning** | Docker services not running | SynapseOS includes built-in in-memory fallback stores for vector search and graph relations when external Docker daemons are offline. |
| **Nebius Token Factory timeout** | Missing API key in `.env` | Configure `NEBIUS_API_KEY` in `.env`, or rely on the built-in deterministic simulation engine for offline testing. |
