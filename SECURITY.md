# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SynapseOS, please send an email to security@synapseos.dev. All security vulnerabilities will be promptly addressed.

**Please do NOT report security vulnerabilities through public GitHub issues.**

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Fix timeline**: Depends on severity

## Security Best Practices

When deploying SynapseOS:

- Always use HTTPS in production
- Keep all dependencies updated
- Use strong, unique passwords for all services
- Enable encryption at rest for databases
- Restrict network access between services
- Monitor logs for suspicious activity
- Regular security audits recommended

## Data Privacy

SynapseOS is designed with privacy-first principles:

- All data is stored locally by default
- No telemetry is sent without explicit opt-in
- Cloud LLM usage is optional and configurable
- Users maintain full control of their data
